# ToggleMaster — AWS Cost Estimate

## Scope

Baseline estimate for the Phase 3 environment in `us-east-1`, assuming 730 hours/month and the infrastructure currently provisioned in AWS.

The inventory below was validated against the live AWS account before this document was created.

## Current provisioned baseline

| Service | Current configuration | Unit price used | Estimated monthly cost |
|---|---|---:|---:|
| Amazon EKS | 1 cluster, Kubernetes 1.35, standard support | USD 0.10/cluster-hour | USD 73.00 |
| Amazon EC2 | 3 x `t3.small`, On-Demand Linux | USD 0.0208/instance-hour | USD 45.55 |
| Amazon EBS | 3 x 20 GiB `gp3` | USD 0.08/GB-month | USD 4.80 |
| NAT Gateway | 1 NAT Gateway | USD 0.045/hour | USD 32.85 |
| Amazon RDS | 3 x `db.t4g.micro`, PostgreSQL, Single-AZ | USD 0.016/instance-hour | USD 35.04 |
| RDS storage | 3 x 20 GiB `gp3` | USD 0.115/GB-month | USD 6.90 |
| ElastiCache | 1 x `cache.t4g.micro`, Redis | USD 0.016/node-hour | USD 11.68 |
| Amazon ECR | ~3.97 GiB currently stored across 5 repositories | USD 0.10/GB-month | USD 0.40 |
| DynamoDB | PAY_PER_REQUEST, empty/near-zero test workload | usage-dependent | ~USD 0.00 |
| SQS | Standard queue, near-zero test workload | usage-dependent | ~USD 0.00 |
| S3 remote state | ~145 KiB state data | usage-dependent | negligible |

**Estimated fixed/base monthly cost: approximately USD 210.22/month.**

## Variable costs not included in the base estimate

The final AWS Pricing Calculator value can be slightly higher because the following depend on real usage or calculator assumptions:

- NAT Gateway data processing: USD 0.045/GB processed;
- internet/data transfer;
- public IPv4 address charges when applicable;
- DynamoDB read/write requests;
- SQS requests;
- ECR data transfer;
- CloudWatch logs/metrics generated by the environment;
- Secrets Manager usage if separately billed;
- backup/snapshot storage above included allowances.

For the FIAP delivery screenshot, use the AWS Pricing Calculator with the current quantities above and retain the calculator screenshot as `DEL-05` evidence.

## Temporary lab perspective

This environment was created for a short-lived academic validation. If it stays online only during implementation/demo windows rather than 24x7 for a full month, the actual bill will be materially lower than the monthly baseline. The largest fixed hourly drivers are the EKS control plane, the three EC2 worker nodes, the NAT Gateway, the three RDS instances, and ElastiCache.

## Cost-control notes

After the final video and report are complete, destroy or scale down the temporary environment to avoid continued charges. Keep the remote state and repository history required for evidence, but do not leave compute/database resources running solely for documentation.
